# Vagas SENAI

Monitor das vagas de estacionamento dos bolsões A, C e H do SENAI Blumenau. Cada bolsão tem um ESP32 com um sensor por vaga, a central ESP32 junta tudo e publica no Supabase, e a página em `vagas.rubysistemas.com.br` mostra as vagas livres em tempo real.

O projeto está começando. As instruções para rodar local, aplicar a migration, configurar o firmware e testar o caminho completo entram aqui junto com o código.
